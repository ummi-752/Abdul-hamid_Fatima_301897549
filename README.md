Case Study:TimaPay — Digital Banking and Fintech Platform

## Organisation Description
TimaPay is a digital banking platform that allows customers to open accounts,
deposit and withdraw money, transfer funds, and view transaction history.
Bank staff can manage accounts and reverse failed transactions.
System administrators handle database configuration, backups, and monitoring.

## Repository Structure
| Folder | Contents |
|--------|----------|
| portfolio-1-database-design/ | ER diagram, SQL schema, normalisation |
| portfolio-2-query-optimisation/ | SQL queries, indexes, execution plans |
| portfolio-3-transactions-concurrency/ | Transaction scripts, isolation level demos |
| portfolio-4-nosql/ | MongoDB collection, validation, comparison |
| portfolio-5-distributed-cloud/ | Replication, sharding, CAP analysis |

## How to Run the SQL Scripts
1. Install PostgreSQL 16
2. Open pgAdmin or psql
3. Run schema.sql from portfolio-1-database-design/

## How to Run the MongoDB Scripts
1. Install MongoDB 7
2. Open mongosh
3. Run schema-validation.js from portfolio-4-nosql/
